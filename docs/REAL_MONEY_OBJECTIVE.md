# ZA141251SA standing objective — real USD earnings only

Effective 2026-09-20. This supersedes any earlier roadmap language suggesting
that provider estimates, demonstrations or agent definitions constitute income.

- Prioritize useful work under genuine client/provider contracts. No income guarantee.
- Use legitimate human/provider accounts and obey automation, geographic, KYC,
  AML, tax and client confidentiality/AI-use requirements. Never create accounts
  for the 4,001+ agent definitions or count those definitions as executable jobs.
- Every connector must expose DISCOVER → ELIGIBILITY → AUTHORIZATION → REAL WORK
  → DELIVERY → PROVIDER CONFIRMATION → PAYOUT → SETTLEMENT VERIFICATION → MISSION WALLET.
  Missing components remain explicitly BLOCKED, not simulated as successful.
- A lead, bid, budget, upload, affiliate commission or platform balance is not
  mission cash. Test fixtures remain isolated from production money.
- Incoming **new earning receipts must be USD** at the shared money-engine boundary,
  even when an operator changes treasury/policy currency. Awin settlement also
  requires USD. No conversion rate or estimated USD value supplies cash.
- Non-USD-origin work would require independently verified actual USD settlement
  and explicit attributable FX/fee evidence. No such conversion adapter is enabled.
- Preserve idempotent historical receipts and legitimate refunds/reversals; do
  not rewrite historical currencies/balances or silently migrate them to USD.
- Verified payout → independently verified mission cash → bounded agent
  allocation/operating costs → owner-approved, provider-confirmed withdrawal.
  Customer funds remain separate. Existing grants, freeze/kill, budgets,
  destinations, holds and uncertainty protections remain mandatory.

## Connector reporting contract

Each completed connector report must state its actual earning mechanism, USD
payment mechanism, required owner setup, automation limits, exact live blockers
and tests. Partial implementations must be labelled partial. The next work
pathway is human-assisted Freelancer fixed-price USD software delivery; it must
not be advertised as an end-to-end earning connector while payout/independent
settlement or genuine account/contract authorization are missing.
