Frequently asked

What happens when a provider credential is missing?

No result is fabricated. The execution fails honestly with provider_not_configured, the required variable is named and the task credit is refunded automatically.

What do the 4,000+ agents actually do?

Each entry carries a real specialization, system instructions, tool permissions, workflow, verification rules and evaluation config. MASTER selects the specialist that fits your goal.

How are credits accounted for?

A task reserves one credit atomically. Success keeps it consumed; failure refunds exactly the same pool. Concurrency cannot double-spend the last credit.

Can I create my own agent?

Yes. Agent Factory lets you define instructions, tools and workflow, then run security review, benchmark, version, deploy, disable and rollback.

Is my workspace isolated?

Yes. Projects, files, knowledge, tasks and execution streams are scoped to your authenticated account and are checked at every read/mutation.
